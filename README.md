# 🚀 Overview

ViperDrop Mobile is the Android companion app for **ViperDrop Desktop**.

It allows you to quickly transfer:

- 📁 Folders
- 📄 Files
- 📝 Text
- 🖼 Images
- 🎬 Videos
- 🎵 Audio
- 📦 APKs
- 📑 Documents

directly between your PC and Android device **without using cloud services**.

Everything happens on your **local network**.

---

# ✨ Features

## 📡 Local Connection

- QR Code pairing
- No account required
- No external server
- No Internet required (LAN only)

---

## 📤 Send

- Files
- Entire folders
- Clipboard text

---

## 📥 Receive

- Download files
- Download folders
- Automatic history
- Progress bar
- Transfer status

---

## 📷 Media Support

Received media are automatically saved inside Android:

| Type | Destination |
|-------|-------------|
| Images | Pictures/ViperDrop |
| Videos | Movies/ViperDrop |
| Audio | Music/ViperDrop |
| Documents | Downloads/ViperDrop |

Images immediately appear inside the Gallery.

---

## 📚 History

Transfer history includes:

- File name
- Size
- Device
- Date
- Transfer direction
- Status
