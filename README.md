# 🚀 Panoramica

ViperDrop è l'app desktop per Windows e Linux che permette di trasferire rapidamente:

- 📁 Cartelle
- 📄 File
- 📝 Testo e link
- 🖼️ Foto e video

tra il PC, il telefono e **altri PC con ViperDrop**, **senza utilizzare servizi cloud**.

Tutti i trasferimenti avvengono esclusivamente sulla **rete locale (LAN)**.

---

# 🆕 Novità della 1.5.0: collegamento tra due PC

Nuova pagina **⇄ Altri PC**: due PC con ViperDrop installato ora comunicano direttamente tra loro.

- 🔍 **Ricerca automatica**: gli altri PC con ViperDrop sulla stessa rete compaiono da soli
- 🔐 **Associazione con codice**: premi **Associa** e conferma che il codice a 6 cifre sia uguale su entrambi gli schermi
- 📤 **Invio in entrambe le direzioni** di file, cartelle complete e testo
- 🖱️ **Trascina e rilascia** file e cartelle sulla scheda del PC
- 📦 **Cartelle grandi** con migliaia di file, approvate con una sola conferma
- ✅ **Controllo di ogni file**: viene confermato solo se arriva con la dimensione esatta
- 🔁 **Ripresa automatica** dei file interrotti da un problema di rete
- ⛔ **Annullamento** da entrambi i PC
- ⌨️ Se un PC non compare, puoi collegarlo **scrivendo il suo indirizzo**

Tutte le funzioni per il telefono restano invariate.

# ✨ Funzionalità

## 📡 Connessione Locale

- Connessione del telefono tramite QR Code
- Dispositivi associati che si riconnettono da soli
- Nessun account richiesto
- Nessun server esterno
- Trasferimenti solo sulla rete locale

---

## 📱 Telefono

- **Android**: app [ViperDrop Mobile](https://github.com/xSteo101/ViperDrop-Mobile)
- **iPhone / iPad**: web app da aggiungere alla schermata Home, senza installare nulla
- Qualsiasi browser: basta scansionare il QR Code

---

## 📤 Invio e 📥 Ricezione

- File, cartelle complete e testo in entrambe le direzioni
- Conferma degli invii in arrivo, oppure accettazione automatica per i dispositivi associati
- Limite per singolo file selezionabile fino a **50 GB**
- Controllo dello spazio libero prima di accettare un invio
- Barra di avanzamento e stato in tempo reale

---

## 🔌 Backup via cavo (Windows)

- Backup di foto e video **originali** dell'iPhone collegato con il cavo USB
- Ogni file viene **verificato** al termine: presenza, dimensione e contenuto
- Ripresa del backup interrotto: copia solo ciò che manca
- **Galleria** del telefono divisa per mese, con selezione e copia delle singole foto

---

## 📚 Cronologia

La cronologia dei trasferimenti mostra:

- Nome del file
- Dimensione
- Dispositivo utilizzato
- Data e ora
- Direzione del trasferimento
- Stato del trasferimento

# 🔒 Privacy

ViperDrop è stato progettato mettendo la privacy al primo posto.

✔ Nessun cloud

✔ Nessun server esterno

✔ Nessuna telemetria

✔ Nessuna raccolta dati

✔ Trasferimenti esclusivamente sulla rete locale

I tuoi file **non lasciano mai la tua rete**. L'unica connessione a Internet è il controllo degli aggiornamenti su GitHub.

---

# 💻 Requisiti

- Windows 10 o Windows 11 (64 bit), oppure Linux 64 bit (`.deb` o AppImage)
- PC e telefono collegati alla stessa rete
- Per il collegamento tra PC: **ViperDrop 1.5.0 o successivo su entrambi i PC** e rete impostata come **Privata**
- Per il backup via cavo: Windows e i driver Apple (app **Apple Dispositivi** o iTunes)

# 📦 Installazione

Scarica l'ultima versione dalla sezione **Release**.

| Sistema | File |
|---|---|
| Windows 10/11 (64 bit) | `ViperDrop-Setup-1.5.0.exe` |
| Linux Debian/Ubuntu (64 bit) | `ViperDrop-1.5.0-Linux-amd64.deb` |
| Linux, qualsiasi distribuzione (64 bit) | `ViperDrop-1.5.0-Linux-x86_64.AppImage` |

[![Scarica](https://img.shields.io/badge/📥%20Scarica-Ultima%20Versione-success?style=for-the-badge)](https://github.com/xSteo101/ViperDrop/releases/latest)

Su Windows, se compare l'avviso di SmartScreen, scegli **Ulteriori informazioni → Esegui comunque**.

Al primo avvio, se Windows Firewall mostra una richiesta, consenti l'accesso sulle **reti private**.

Apri ViperDrop, scansiona il QR Code con il telefono oppure vai su **⇄ Altri PC** per collegare un altro computer, e inizia subito a trasferire i tuoi file.
