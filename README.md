# 🚀 Panoramica

ViperDrop Mobile è l'app Android ufficiale di **ViperDrop Desktop**.

Permette di trasferire rapidamente:

- 📁 Cartelle
- 📄 File
- 📝 Testo
- 🖼️ Immagini
- 🎬 Video
- 🎵 Audio
- 📦 File APK
- 📑 Documenti

direttamente tra il PC e il dispositivo Android **senza utilizzare servizi cloud**.

Tutti i trasferimenti avvengono esclusivamente sulla **rete locale (LAN)**.

---

# ✨ Funzionalità

## 📡 Connessione Locale

- Connessione tramite QR Code
- Nessun account richiesto
- Nessun server esterno
- Nessuna connessione Internet necessaria
- Trasferimenti solo sulla rete locale

---

## 📤 Invio

È possibile inviare:

- 📄 File
- 📁 Cartelle complete
- 📝 Testo e link

---

## 📥 Ricezione

- Download dei file
- Download delle cartelle
- Cronologia automatica
- Barra di avanzamento
- Stato del trasferimento in tempo reale

---

## 📷 Supporto Multimediale

I file ricevuti vengono salvati automaticamente nelle cartelle corrette di Android.

| Tipo | Destinazione |
|------|--------------|
| 🖼️ Immagini | Pictures/ViperDrop |
| 🎬 Video | Movies/ViperDrop |
| 🎵 Audio | Music/ViperDrop |
| 📄 Documenti | Download/ViperDrop |

Le immagini vengono inoltre visualizzate automaticamente nella Galleria.

---

## 📚 Cronologia

La cronologia dei trasferimenti mostra:

- Nome del file
- Dimensione
- Dispositivo utilizzato
- Data e ora
- Direzione del trasferimento
- Stato del trasferimento

---

# 🔒 Privacy

ViperDrop è stato progettato mettendo la privacy al primo posto.

✔ Nessun cloud

✔ Nessun server esterno

✔ Nessuna telemetria

✔ Nessuna raccolta dati

✔ Trasferimenti esclusivamente sulla rete locale

I tuoi file **non lasciano mai la tua rete**.

---

# 📱 Requisiti

### Android

- Android 7.0 o superiore
- Fotocamera (per la scansione del QR Code)
- Connessione alla stessa rete Wi-Fi del PC

### PC

- Windows 10 o Windows 11
- ViperDrop Desktop installato

# 📦 Installazione

Scarica l'ultima versione dell'APK dalla sezione **Release**.

Abilita l'opzione:

```
Installa app da origini sconosciute
```

Installa l'APK.

[![Scarica APK](https://img.shields.io/badge/📥%20Scarica%20APK-Ultima%20Versione-success?style=for-the-badge)](https://github.com/xSteo101/ViperDrop-Mobile/releases/latest)
